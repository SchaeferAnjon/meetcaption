# 会议字幕 v3：Raycast 风格界面、首次引导、项目

v2（两路声音 + 声纹、ChatGPT 订阅、AI 答题、术语悬停）的主进程和各模块已经接好，见 `docs/v2-设计.md` 和 `docs/v2-integration/`。v3 在它上面做三件事。用户原话：界面太丑，要 Raycast 那种风格；装好后第一步录声纹、第二步绑定 OpenAI 订阅；设置和主页布局都乱；开会一定有项目，可能有多个综合项目，要想清楚怎么放。

全局约定同 `docs/v2-设计.md`（不许破折号、不 commit、密钥规矩、不放扬声器、不开真实麦克风、npm test 通过、测试用隔离目录）。

## 一、项目怎么组织

**一个根目录，一个项目一个子文件夹，每场会议属于且只属于一个项目。** 跨项目的事交给 AI：生成纪要时把全部项目的名字和简介给模型，每条待办和 DDL 各自标到对应项目。所以一场会里聊了三个项目，会议记录放在它的主项目下，三个项目的「待办」页各自能看到归它的那几条。

```
<根目录>（默认 文稿/会议字幕，设置里可改）
  <项目名>/
    project.json          { id, name, color, icon, description, context, keywords, profile, language, createdAt, archived }
    <YYYY-MM-DD HH.mm 标题>/
      session.json  字幕记录.md  会议纪要.md
  未归类/                  默认项目，id 固定 'inbox'，不能删
```

- `project.json` 跟着文件夹走，拷走整个项目文件夹就是完整的项目。项目 id 稳定（创建时生成），改名时同时改文件夹名。
- 原来放在全局设置里的「会议背景 context、术语 keywords、我的资料 profile、对方语言 language」挪到项目里。全局设置里保留的值迁移成「未归类」项目的默认值；新建项目时可以从某个项目复制。
- 会议 session.json 加 `projectId`。会议可以移到别的项目（移动文件夹，名字冲突就加后缀）。会议 id 仍是会议文件夹名，全局唯一（创建和移动时保证）。
- v1/v2 放在根目录下的会议文件夹，启动时自动迁到「未归类」。
- 纪要生成后再做一次结构化提取，写进 `session.summary.items`：
  `[{ id, text, due: 'YYYY-MM-DD' | null, dueText, owner: 'me' | 'other' | null, projectId, quote, at }]`，每条有 `done` 状态可勾选。纪要 prompt 带上项目清单，相对日期按会议日期换算。
- 开会前要选项目：主窗口当前选中的项目就是这次会议的项目，开始按钮上写明「在「XX」里开始会议」；命令面板和托盘菜单也能切项目。引擎开始时用这个项目的 context、keywords、profile、language。
- 搜索：命令面板里能搜会议标题、纪要、字幕文字和待办（主进程扫 session.json，几百场会没问题）。

## 二、界面风格：Raycast

参考 raycast.com 和 Raycast 本身（可以用 Playwright 打开 raycast.com 截图参考，别照搬它的品牌色和 logo）。要点：

- **暗色优先，跟随系统**，浅色模式同样精致。中性灰为主：暗色背景约 #1b1b1d，表面叠 rgba(255,255,255,0.04 到 0.07)，描边 rgba(255,255,255,0.08)，正文 #ececec，次要 #9a9aa0，更弱 #6b6b70。强调色克制，只用在主按钮、选中态和少量图标底色上，选一个和应用图标呼应的蓝紫色。
- 字体：Mac 用系统字体（SF），13px 为主，标题 15 到 17px 半粗；Windows 用 Segoe UI Variable / Microsoft YaHei UI。行高紧凑。
- 组件：
  - 列表行 36 到 40px 高：左边 24px 圆角方块里放 16px 线性图标（彩色底），标题，灰色副标题，右侧是日期、计数、快捷键徽标。选中行是淡色圆角高亮，上下键可以移动，回车打开。
  - 快捷键徽标（kbd）：小圆角描边块，11px。
  - 顶部搜索框 / 命令面板（⌘K / Ctrl+K）：大输入框，下面是分组的结果列表，底部动作条显示「↵ 打开」「⌘K 操作」。
  - 开关用 toggle，不用复选框；分段控件；下拉；输入框都是低对比度底色、细描边、聚焦时强调色描边。
  - 卡片少用；靠分组标题、分隔线和留白组织层级。
  - 图标用 Lucide（ISC 许可），只拷需要的 SVG 进 `src/renderer/shared/icons.js`，不引运行时依赖。
- 窗口外观：Mac 用 `titleBarStyle: 'hiddenInset'` + 侧栏 `vibrancy: 'sidebar'`（侧栏半透明毛玻璃）；Windows 11 用 `backgroundMaterial: 'mica'` + `titleBarStyle: 'hidden'` 和 `titleBarOverlay`（颜色跟主题）。拖动区域要留好。
- 字幕窗和答题框也换成同一套：深色半透明（约 rgba(28,28,30,0.86)），1px 细描边，12px 圆角，柔和阴影，标题条上用 kbd 徽标提示快捷键。

## 三、信息架构

### 主窗口

左侧栏（毛玻璃）：
- 顶部：搜索框（点开就是命令面板，⌘K）。
- 「首页」「待办」两个固定入口。
- 「项目」分组：每个项目一行（彩色图标、名字、会议数），最下面「新建项目」。未归类放最后。
- 底部：当前状态小条（声纹是否录好、AI 账号、识别服务，哪个没配好就显示黄点，点了去对应设置），设置按钮（⌘,）。

右侧内容区视图：
- **首页**：大的「开始会议」按钮（带项目选择下拉，显示当前项目），最近 3 天的会议列表，逾期和 7 天内到期的待办，没配置好的项给一条引导。
- **会议进行中**：开始后自动切到这里。顶部一条：项目名、计时、两路音量条（我 / 对方）、隐藏字幕（kbd）、让 AI 回答（kbd）、停止。下面左右分栏：左边实时记录（我 / 对方 区分，问题句标记，术语虚线悬停解释），右边 AI 答题流（和悬浮答题框同步，最新在上）。
- **项目页**：标题区（图标、名字、一句描述，可直接改）；「在这个项目里开始会议」按钮；标签页：会议（列表，右侧显示时长和有无纪要）、待办与 DDL（归到这个项目的全部待办，按到期分组）、资料（会议背景、术语、我的资料、对方语言，编辑即保存）。项目操作（改名、换颜色图标、归档、删除）放在「…」菜单里。
- **会议详情**：标题（可改）、所属项目（可移动）、时间和时长；标签页：纪要（生成 / 重新生成、额外要求、复制）、待办（这场会提取出的条目，可勾选，显示归属项目）、字幕记录、AI 答题记录、术语表。
- **待办**：所有项目的待办，按「已逾期 / 今天 / 本周 / 以后 / 没有截止」分组，每条显示项目标签和来源会议，可勾选，可按项目筛选，默认隐藏已完成。

### 设置窗口（独立窗口，⌘, 打开）

左边分区列表，右边一组组「左标签、右控件」的行（像 macOS 系统设置和 Raycast 设置）：
- 通用：开机启动（可选）、主题（跟随系统 / 深色 / 浅色）、保存位置、屏幕共享时隐藏字幕和答题框。
- 账号与 AI：ChatGPT 订阅登录（推荐，显示账号和套餐、退出）/ OpenAI API Key / 其他兼容服务；翻译模型、总结模型、答题模型；测试。
- 语音识别：豆包 / OpenAI 二选一和各自的密钥；出字速度；测试连接。
- 声纹：状态、重新录制、删除、阈值（高级）。
- AI 答题：开关、自动回答、带屏幕截图、回答语言。（「我的资料」在项目里，这里提示去项目资料里填。）
- 字幕与答题框：字号、行数、背景深浅、颜色、显示译文、术语解释、显示我说的话、调整位置、恢复默认位置。
- 快捷键：显示 / 隐藏全部、让 AI 回答刚才的问题、打开命令面板（应用内）。
- 麦克风：是否同时录我、选择设备。
- 关于：版本、数据位置、使用说明。

### 首次引导（独立窗口，第一次启动出现，之后能从设置里重新打开）

步骤条 + 每步一屏，底部「上一步 / 下一步 / 稍后再说」：
1. **录声纹**：说明用途，一段中英混读的朗读文字，录 12 秒，实时音量条和倒计时，完成后显示「已录好」。
2. **连接 AI**：推荐「用 ChatGPT 账号登录」（用订阅额度做翻译、纪要、答题）；或者填 OpenAI API Key。
3. **语音识别**：豆包（填 App ID、Access Token，测试连接）或 OpenAI（用上一步的 API Key）。
4. **建第一个项目**：名字、一句话背景、术语（可选）、我的资料（可选，面试时放简历要点）。
5. **试一下**：Mac 上申请系统录音和屏幕录制权限（说明为什么），「播放点声音看音量条」的 5 秒测试，展示字幕样子和两个快捷键，完成。

## 四、分工（v3 workflow）

- **DS 设计系统**（先做）：`src/renderer/shared/`：tokens.css（暗 / 浅两套变量，跟随系统，支持强制主题）、ui.css（列表行、kbd、按钮、toggle、分段、输入、下拉、菜单、弹层、命令面板、侧栏、标签页、toast、空状态）、icons.js（Lucide 子集）、ui.js（小工具：el()、toggle()、kbd()、toast()、menu()、commandPalette()、列表键盘导航），外加 `src/renderer/shared/styleguide.html` 展示全部组件（暗和浅各截图）。
- **P 主进程与数据**（和 DS 同时做）：项目存储和迁移、会议按项目存取和移动、待办提取和聚合、搜索、引擎按项目取上下文、设置窗口和引导窗口、窗口外观（hiddenInset / vibrancy / mica）、托盘里的项目切换、preload 新 API。
- **U1 主窗口**（DS 之后）：`src/renderer/control/` 全部重写成上面的主窗口。
- **U2 设置 + 引导 + 悬浮窗换肤**（DS 之后）：`src/renderer/settings/`、`src/renderer/onboarding/`，以及 overlay.css、answer.css 换成同一套风格（只改样式和必要的结构，不动逻辑）。

### preload 新增 API（P 实现，U1/U2 调用，名字必须一致）

```
listProjects() → [{ id, name, color, icon, description, meetings, openTodos, archived }]
getProject(id) → project（含 context、keywords、profile、language）
createProject(p) → project；updateProject(id, patch) → project；deleteProject(id)（会议移到未归类）
setCurrentProject(id)；init() 返回值新增 projects、currentProjectId、onboarding：{ done, voiceprint, ai, asr, project }
listSessions({ projectId }) → 每条多 projectId、answers、todos（未完成数）
moveSession(id, projectId) → session
listTodos({ projectId, includeDone }) → [{ ...item, sessionId, sessionTitle, sessionStartedAt, projectId }]
updateTodo(sessionId, itemId, patch) → item
search(query) → { projects, sessions, todos }（每条带匹配片段）
openSettings(section?)；openOnboarding()；finishOnboarding()；showMain()
start({ projectId }) 用指定项目开会
事件：'projects:changed'、'sessions:changed'、'todos:changed'
```

设置窗口和引导窗口也用 `preload/control.cjs`（同一套 window.app）。
